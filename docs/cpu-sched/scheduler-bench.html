Cases from the book

Jobs

Per job

Turnaround
completion − arrival. How long until the job is done (OSTEP's first metric).
Response
first run − arrival. How long until the job starts; what interactive users feel.
Wait
turnaround − length. Time spent ready but not running; the homework's scheduler.py reports it too.
Fairness
Jain's Fairness Index, which the chapter names as a fairness measure, applied here to each job's CPU share while it is in the system (length ÷ turnaround). 1.00 = every job progresses at the same rate; lower = some jobs are starved while others finish.
